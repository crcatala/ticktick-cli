# Add GitGuardian secret scanning

Add GitGuardian ggshield-action workflow for secret scanning to prevent accidental credential commits.

Create .github/workflows/gitguardian.yml:
- Run on push and pull_request
- Use fetch-depth: 0 for full history scan
- Pin action to SHA

Requires GITGUARDIAN_API_KEY secret to be configured in repo settings.
